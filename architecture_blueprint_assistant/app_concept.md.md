# Application Concept - Bloom Tracker
## Application
User-driven flower blooming tracker
## Core Features
- Map with markers locating flowering trees and plants
- Markers shows information on the plant and predicted blooming time
- Indicates currently blooming plants
- Users can submit photos of plants for identification and tracking
## Users
- Observers: want to find blooming plants and learn more about them
- Contributors: submit photos to add new trees and plants
## Constraints
- Scale to 10k concurrent users
- Mobile-first design
