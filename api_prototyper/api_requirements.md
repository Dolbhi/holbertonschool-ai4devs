# API Requirements – Plant API

## Domain
Blooming plant tracker

## Target Users
- Users: look up where and when plants are blooming
- Contributors: submit photos of blooming plants or help to identify submitted photos

## Core Operations
- Add plant
- Add plant photo
- Add plant identity
- Update bloom prediction
- Search for nearby plants
- Search for plant by species
- Search for plant by colour
- Remove photo
- Merge plants

## Data Rules
- Plant IDs must be unique
- Valid GPS position

## Non-Functional
- Response time < 200ms
